# AOA Lab Practicals – Java

Each experiment folder contains its Java source file and a README with aim, sample output, English/Hinglish explanation, complexity, and run commands.

## How to run
1. Open the required experiment folder in VS Code.
2. Open the `.java` file in that folder.
3. Compile: `javac ClassName.java`
4. Run: `java ClassName`

Use the sample inputs shown in each README to reproduce the sample output.
